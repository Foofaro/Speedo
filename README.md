# Speedo

A live GPS speedometer (km/h) with spinnable 3D live weather, built as one `index.html` file.

Live site: https://foofaro.github.io/speedo/ (GitHub Pages)

- Tap the 3D weather for full weather info; tap the speed for a full-screen speedometer.
- The side tab on the right shows or hides the extra details and the tab bar.
- Open it in Safari, allow location, then Share → Add to Home Screen.
